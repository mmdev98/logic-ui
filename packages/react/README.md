# @logic-ui/react

Unstyled advanced React components for accessible interfaces.

Built on [Base UI](https://base-ui.com) and extending it: every Base UI component is re-exported
under the same path, plus components Base UI doesn't have. It is a drop-in replacement, so an app
already on Base UI can switch without changing its imports. Alias it in your app's `package.json`:

```json
{
  "dependencies": {
    "@base-ui/react": "npm:@logic-ui/react@0.3.0"
  }
}
```

```sh
pnpm add @logic-ui/react
```
